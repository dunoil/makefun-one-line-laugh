An entry for the make.fun bounty "The One-Line Laugh" ($5 prize across the top three lines). The program writes a single funny line, at most 200 characters, to `/output/entry.txt`.

> "My fridge emailed me a grocery list this morning, and honestly, it shops better than I do."

Character count: 90

## How to run

```sh
node main.ts
```

By default it writes to `/output/entry.txt`. To write elsewhere, set `OUTPUT_PATH`:

```sh
OUTPUT_PATH=/tmp/one-line-laugh-out/entry.txt node main.ts
```
